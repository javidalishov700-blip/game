# FLINCH

Six lanes. Wait. Then strike.

A spike flies at a glass core. Tap the **correct wedge** when it turns **gold**. Too early is a flinch (you live, combo dies). Too late costs a life. Ghosts must be **left alone** — tapping one hurts, letting one pass scores. Later waves overlap, pay gold double, and some spikes **switch lanes** mid-flight.

Three lives. Wave clear bonus. Consecutive gold hits stack **2x → 3x → 4x** (up to 8x).
