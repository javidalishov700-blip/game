# FLINCH

Wait. Then tap.

One button. A spike flies at a glass core. Tap when it turns **gold**. Too early is a flinch (you live, combo dies). Too late is a slow-motion shatter.

Consecutive gold hits stack **2x → 3x → 4x** (up to 8x). Tap to play, tap to retry. No menus.

```bash
npm install
npm run dev
```
